# ID3 Project

This project is a health diagnosis system using the ID3 algorithm.

## Features
- Get instant preliminary assessment based on your symptoms and medical history.
- View your previous diagnosis reports and track your health over time.
- Search for doctors by specialty, location, and rating.
- View detailed doctor profiles, including contact information.
- Interactive and user-friendly interface.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/abeli-o/ID3-project.git
2. Navigate to the project directory:
   ```bash
      cd ID3-project

3.Install dependancies:

     pip install -r requirements.txt

Usage

   ```bash

2. open your browser and navigate to
